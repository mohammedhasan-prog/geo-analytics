System Requirements Specification (SRS): Geospatial File Measurement API
System Goals:
Process geospatial files to extract measurements (e.g., area, distance, perimeter) with ultra-low response times (latency) and the ability to handle concurrent requests at scale (throughput).

Recommended Tech Stack:

Backend: Go (fiber/gin) or Rust (Actix-web) for maximum throughput, OR Python (FastAPI) with C-optimized geospatial libraries.

Geospatial Engine: GDAL bindings, GEOS, or PostGIS.

Concurrency: Asynchronous I/O and message queues (Redis/RabbitMQ) for large files.

Immediately return a 202 Accepted with a job_id.

Offload the measurement calculation to a background worker pool using a lightweight message broker (like Redis).

Create a polling endpoint (GET /api/v1/measure/{job_id}) to retrieve the status and final results of the calculation."

Agent Prompt Step 5:
